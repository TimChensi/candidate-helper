# Использование географических данных

Географический справочник `geo-cities.js` подготовлен на основе набора данных [ru-cities](https://github.com/epogrebnyak/ru-cities) (авторы Evgeniy Pogrebnyak и Kirill Artemov): 1117 городов России, их регионов и координат. Первичные данные включают сведения Росстата и координаты, полученные из открытых географических источников, в том числе OpenStreetMap.

- Описание и публикация: https://zenodo.org/records/5151423
- Исходный CSV: https://github.com/epogrebnyak/ru-cities/blob/main/assets/towns.csv
- © OpenStreetMap contributors, Open Database License (ODbL): https://www.openstreetmap.org/copyright
- Для сведений о лицензии исходного набора данных: https://zenodo.org/records/5151423

Преобразования для сайта: уменьшена точность координат до пяти знаков после запятой, данные упакованы в JavaScript и упорядочены по численности населения для поиска. Для названия региона без точного населённого пункта расчёт выполняется от географического ориентира (крупнейший город соответствующего региона по исходному набору данных), а не от точного адреса. Для направлений оформления «Татарстан» и «Ленинградская область» используются соответственно ориентиры Казань и Гатчина. Длина по прямой не равна расстоянию по автомобильной или железной дороге.
